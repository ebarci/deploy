# Prácticas de QA y automatización

Este repositorio contiene mis ejercicios y pruebas automatizadas realizados durante la cursada de QA en UNTREF.

## Contenido

- **Python:** ejercicios de números primos y ecuaciones cuadráticas.
- **Pruebas de API:** validaciones de respuestas de PokeAPI.
- **Automatización web:** pruebas en SauceDemo de inicio de sesión, ordenamiento de productos, carrito y compra.
- **Reportes HTML:** resultados de las pruebas ejecutadas.

## Herramientas utilizadas

Python, Selenium WebDriver, pytest, pytest-html y Visual Studio Code.
